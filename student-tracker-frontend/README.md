# Student Tracker — Frontend (SaaS UI)

Modern, clean, professional scaffold ready for a Node/Express + PostgreSQL backend.
- Light-first design with automatic dark mode support
- Consistent topbar, page headers, cards, tables, and forms
- Role-aware navigation (Admin / Instructor / Student)

Open `index.html` to use the demo. Replace `Auth.fakeLogin` and `api.*` stubs with your real API.
